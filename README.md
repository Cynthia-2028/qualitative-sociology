# 质性研究 · Qualitative Sociology

> 一个覆盖"从理解到产出"的质性研究工作台：把方法学知识变成可执行的工序、判据与话术。

质性研究的门槛不在"会不会做访谈"，而在**判断**：这个问题该用哪种取向？我抽的这些人能不能回答它？我写的是主题还是话题？评审说"只是描述"，我该补什么？这个技能把这些判断拆成可核对的判据，并把七类常见需求接到各自的工序上。

## 它覆盖七种场景

| 场景 | 用户说的话 | 交付物 |
|---|---|---|
| **科普解释** | "什么是质性研究""和定量什么区别" | 四段式解释：定义 → 对照 → 例子 → 边界 |
| **现象解读** | "用质性视角看考公热""这个现象说明了什么" | 六步解读：困惑 → 切口 → 可观察痕迹 → 三个竞争解释 → 反例 → 边界 |
| **专业答疑** | "主题和编码有什么区别""饱和要多少人" | 三段式：结论 → 判据 → 例外 |
| **学习教学** | "我该怎么学""帮我设计一节课" | 七天 / 二十一天 / 九十分钟三套路径 + 自测题 |
| **选题设计** | "我想研究 X 怎么做""这个题目能做质性吗" | 六步工序 + 开题一页纸 |
| **论文写作** | "方法节写什么""结果部分怎么组织" | 结构模板 + 方法节十二必报项 + 逐段改法 |
| **质量评估** | "这篇论文好不好""帮我打分" | 百分制评分（九维 + 硬伤扣分）+ P0/P1/P2 清单 |

## 它和"方法学教材摘要"的区别

1. **每一个数字都带性质**：实证测定 / 建议值 / 无指南。主题饱和的 9 次访谈不能拿去支撑理论结论；反身性取向本就没有最小样本量。
2. **每一个判断都带判据**：不写"分析不够深入"，而写"九个主题里五个是单词命名、无统合概念，属话题而非主题"。
3. **承认分歧**：饱和、编码一致性、rapport、成员核查、AI 角色这五处，学界并无共识；技能先并列立场与前提，再给建议。
4. **不做虚假引用**：不编造作者、年份与引文；用户要出处时，给可核查的方法学描述。

## 怎么用

**解释一个概念**：直接问"什么是主题分析"，技能会先确认你走的是哪一派，再给定义、判据与边界。

**解读一个现象**：给一个现象，说"用质性视角看这件事"。技能会给六步解读框架，并明确区分"当事人的解释"与"分析者的解释"。

**评估一篇稿子**：把稿件转成 `.txt` 或 `.md`，说"帮我打分"。技能先跑十问快评，再给九维百分制评分，每维附一句证据，最后出 P0/P1/P2 清单。

**机械核对（可选）**：

```bash
python scripts/quality_scan.py 稿件.md
python scripts/quality_scan.py 稿件.md --json
```

它按关键词核对十二类报告要素是否出现，并标出"主题浮现""以饱和代替论证""一致率误用"等已知失分表述。**它不评质量**；命中也可能是空话，未命中也可能是换了说法。

## 三条使用提醒

1. **它会先问、再答**。比如你说"我做主题分析"，它要先确认是哪一派；你说"我访谈了 25 人"，它要先问这 25 是访谈次数还是人数。
2. **它会给坏消息**。如果稿子的问题在主题结构而不在文字，它会直说，不会帮你润色句子来掩盖结构问题。
3. **它不替你采集数据**。所有示例都标注了"框架演练，不是研究发现"；涉及真实田野时，伦理判断留给你。
