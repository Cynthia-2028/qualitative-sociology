# 09 选题与设计：从"我关心某个现象"到"可执行的质性研究"

> 用于回答"我想研究 X，怎么做""这个题目能不能做质性""问题是不是太大了""开题报告怎么写""导师说我没有问题意识怎么办"。
> 核心方法：**把"关心"翻译成"可被经验材料裁决的困惑"**，再翻译成"能被这套方法回答的问题"。

---

## 一、六步工序

### 第 1 步 定位现象，不定位概念

先写一句不用术语的话：**"我感到困惑的是，____在____的情况下，居然会____。"**

- 坏例："我想研究数字劳动与主体性建构。"
- 好例："我感到困惑的是，明明知道平台在抽成，一些骑手还是会主动替平台说话。"

**判据**：这句话能否让一个外行点头说"哦，这确实奇怪"。

### 第 2 步 把"奇怪"拆成三种可能

| 类型 | 你在问什么 | 对应的质性路径 |
|---|---|---|
| 意义型 | 他们如何理解这件事？ | 主题分析、现象学、叙事 |
| 过程型 | 这件事如何一步步发生？ | 扎根理论、过程追踪、民族志 |
| 机制型 | 什么在维持它？在什么条件下反转？ | 案例研究、扩展个案、过程追踪 |

**动作**：三种都写一句，然后选"最不能替换"的那一个——即其他方法答不了的那一个。

### 第 3 步 加边界：谁、何地、何时、何种情况

把问题收窄到"可被观察"：

> 在原句后加三个限定：**人群 + 情境 + 时间/阶段**。

**判据**：收窄后，你能说出"我要找什么样的人、在什么地方、问什么"。

### 第 4 步 找"漏掉的那一半"

不要写"现有研究不足"，而要写："现有解释能说明 A，但说明不了 B。" B 就是你的入口。

**三种合法的 B**：

1. **机制缺口**：知道结果，不知道过程。
2. **意义缺口**：知道行为，不知道当事人如何理解。
3. **条件缺口**：知道一般情况，不知道在什么条件下反转。

### 第 5 步 选设计（指向 02）

用 02 的"问题类型 → 方法匹配矩阵"选定取向，再回答：

- 分析单位是什么（人？事件？关系？话语？案例？）
- 比较单位是什么（跨人群？跨地点？跨时间？）
- 资料从哪来、能否拿到、要不要伦理审查

### 第 6 步 做"可行性四问"

1. **进入可行性**：我能接触到这些人/这个场域吗？靠什么关系？
2. **伦理可行性**：有些人群（如医生谈自己的病人、涉罪人群）难以在不伤害的前提下研究，是否需要换抽样策略？
3. **时间可行性**：我的方法论要求的时间（民族志数月到数年）与我的学制/项目期匹配吗？
4. **能力可行性**：我是否具备这门方法的技术（如话语分析的细读能力、现象学的悬置训练）？若不具，是否有替代路径？

**四问中任何一问过不了，就换设计，不要靠意志力硬推。**

---

## 二、好选题的四条判据与一条反向判据

**四条正向判据**：相关（对谁相关）、及时（为什么是现在）、重要（改变了什么理解）、有趣/能唤起（读者会想读下去）。

**一条反向判据（最好用）**：

> 把研究结论先写成一句话，念给同行听。
> - 如果对方说"**这很明显**"——题目失败。
> - 如果对方说"**这很有意思，但那怎么可能**"——题目成立。

**第二反向判据**：如果这个研究只确认了既有假设，它会被人承认"真"，但不会被承认"有价值"。

## 三、六种常见选题病与改法

| 病 | 表现 | 改法 |
|---|---|---|
| 概念先行 | 题目由理论词堆成（"……视域下的……建构"） | 退回第 1 步，用一个具体困惑重写 |
| 过大 | "中国青年的价值观变迁" | 加人群 + 情境 + 阶段；缩到一个可比单位 |
| 假问题 | "X 与 Y 有关系吗" | 改成"在什么条件下、通过什么过程、对谁而言" |
| 规范问题伪装成经验问题 | "应该如何……" | 拆成"人们实际上如何理解/做"，把"应该"留给讨论 |
| 方法找题目 | 先决定做扎根理论，再找能做的题 | 从问题类型出发重选（02 矩阵） |
| 无法裁决 | 问题无法用任何材料回答 | 加"如果我的答案是 A，我会在材料里看到什么" |

## 四、开题一页纸（可直接交付）

```
一、困惑（一句不用术语的话）：
二、现象的三重描述（意义 / 过程 / 机制 各一句）：
三、研究问题（2–4 个，带问号）：
   RQ1:
   RQ2:
四、漏掉的那一半（机制/意义/条件缺口，指出具体是哪一种）：
五、取向与理由（为何不用邻近方法：一句话）：
六、分析单位 / 比较单位：
七、抽样（逻辑 + 维度 + 格子 + 每格人数 + 停止判据）：
八、资料类型与获取途径（含权限与伦理审查）：
九、分析路径（写到第三步）：
十、质量动作（至少四项）：
十一、预期贡献（指名：理论/启发/实践/方法）：
十二、最大脆弱点与应对：
```

## 五、把题目磨成"问题句"的三个动作

1. **去名词化**：把"……的建构""……的逻辑"改成动词句（"人们如何把……说成……"）。
2. **加条件**：在句尾加"在……条件下""对于……而言"。
3. **加对照**：明确"和什么相比"（不同群体、不同时期、不同平台、不同制度位置）。

**示例演化**：

- 原句：青年就业焦虑的话语建构。
- 去名词化：青年如何谈论自己的就业处境？
- 加条件：在经历过一次失败求职之后，青年如何重新讲述自己的处境？
- 加对照：与未经历失败者相比，他们的讲述在"责任归属"上有什么不同？

## 六、选题讨论的对话方式（给用户做教练时用）

**不要**直接给题目，而是按顺序问四个问题，让用户自己收窄：

1. "你第一次觉得这件事奇怪，是在什么场景里？"（找经验起点）
2. "如果只能带走一个画面，你会带哪个？"（找分析单位）
3. "你猜是什么在维持它？"（找机制假设）
4. "如果猜错了，你会看到什么？"（找可否证性）

四问答完，题目通常已经浮出来了。此时再给 2–3 个可选的问题句，标出各自的代价（数据可得性、伦理风险、理论增量）。

---

## 七、选题的伦理前置（很多题目死在这里）

- **可推测披露**：研究对象是小群体时（某县某校的某类教师），再详细的匿名也可能被认出。选题阶段就要评估"能不能安全地写"。
- **双重身份**：研究自己所在的单位/群体，会同时带来进入便利与表达约束；须提前设计"哪些话不能写"。
- **弱势群体**：涉及未成年人、患者、涉罪人群、无证移民时，知情同意的"自愿"需要额外论证。
- **线上数据**：公开可访问 ≠ 可研究 ≠ 可引用；社群规范可能明确禁止外部研究。

**判据**：如果一个题目让你在写作时不得不"美化"研究对象或"隐藏"关键发现，它可能不是合适的题目。
