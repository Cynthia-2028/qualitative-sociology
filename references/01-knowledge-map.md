# 01 知识地图：质性研究的定义、概念与谱系

> 本文件承担"科普 + 讲解 + 查词"三类任务。用于回答"什么是质性研究""它和定量什么关系""某个术语到底指什么""怎么系统学"。
> 用法：先读第一节确定口径，再按需跳到概念词典或谱系表。回答用户时，先给一句定义，再给判据，最后给边界。

---

## 一、定义：一句话与六个维度

**一句话**：质性研究是以"语境 + 声音"的深度与丰富性去理解社会现象的方法论，追问的是**什么、如何、为何、在何种条件下、对谁而言**，而不是"有多少"。

**六个维度上的"是/不是"**（可直接用于纠正误解）：

| 维度 | 是 | 不是 |
|---|---|---|
| 焦点 | 存在、意义、过程、机制 | 不是可推广性、不是比例估计 |
| 性质 | 语境与声音的厚与富；建构/解释取向；把研究者主体性当洞见来源 | 不是轶事，不是"没有根据的主观感想" |
| 方法 | 开放式提问、深度访谈、焦点小组、参与观察、文本与影像 | 不靠数值测量与统计检验立论 |
| 洞见类型 | 细致、复杂、经验谱系清晰；现实在研究者与参与者之间被建构 | 不提供"超然客观"的说明；不是一套万能方法 |
| 严谨来源 | 系统的方法程序 + 反身性实践 + 可信赖性标准 | **并不比定量更不严谨、更低一等** |
| 适用边界 | 复杂、语境丰厚的现象（如新出现的消费动机、制度落地的过程） | 不适合"某人群持某观点的比例是多少"这类分布问题 |

**三种常见误解与纠正**：

1. "质性不严谨" → 严谨性来自方法论而非统计：延长投入、负面个案分析、审计轨迹、成员反思、同行审议，都是可核查的严谨动作。
2. "质性就是主观" → 它承认主体性，但同时要求结论"拴在经验材料上"：每一条主张都要能回指到具体片段。
3. "什么都能用质性" → 适用性取决于现象性质、问题类型与目标。要估计总体分布，应换概率抽样与统计推断。

**和定量的关系**：不是对立，而是分工。定量求精确（precision），质性求丰富（richness）；质性产出的是"历史与文化上被定位的知识"，其外推走的是**可迁移性**与**分析性概括**，由读者在自己的处境里完成，而不是靠随机样本的代表性。

## 二、概念词典（按使用频率排序，答"这是什么意思"时直接用）

### 2.1 范式层

- **本体论 / 认识论**：前者问"社会现实是什么"（单一客观？多重建构？），后者问"我们如何能知道它"。选方法前先答这两问，否则会出现"宣称建构主义却用验真手段"的错配。
- **Big Q / small Q**：Big Q 指技术与价值全属质性的研究取向（承认意义情境化、研究者是工具）；small Q 指在实证主义框架内使用质性技术（追求编码一致、控制"偏差"）。两者混用而不自知，叫 **confused q**。
- **方法论一致性（methodological congruence）**：从本体论—认识论—研究问题—抽样—收集—分析—写作，全线对齐。不一致分两类：**技术不一致**（让工具做它做不了的事）与**范式不一致**（照抄表面程序，丢掉解释与反身性）。
- **方法崇拜（methodolatry）**：把"走完标准流程"本身当作质量证明。流程是脚手架，不是优越性。
- **理论负荷**：任何方法都带理论预设。声称"归纳所以无理论"是误读——**归纳不产生理论**，只能完成分类。

### 2.2 设计层

- **目的性抽样**：按研究问题挑选"能提供信息"的个案，不追求代表性。
- **理论抽样**：边分析边决定下一个访谁/去哪，目的是补足范畴的属性与维度。
- **复制逻辑**：多案例研究遵循"逐字复制（预期相似结果）/ 理论复制（预期相反结果）"，不是抽样逻辑。
- **关键个案 / 极端个案 / 启示个案**：分别用于检验理论、放大机制、揭示通常被遮蔽的运作。
- **分析性概括**：把发现提升到理论命题层面，再让读者判断可否迁移到自己情境，而非统计外推。

### 2.3 收集层

- **半结构化访谈**：有提纲但保留追问弹性。**"结构化访谈"在严格意义上并不存在于质性传统**——若要跨人可比的固定选项，那实质是口头施测问卷。
- **深描 / 厚描述（thick description）**：把行为放回意义脉络，交代语境、互动与叙事丰度，让读者"看见"而不只是"被告知"。
- **厚建构（thick construction）**：在厚描述之上再加一层分析性建构——对日常建构做科学建构，目标是造出新对象，而非验证旧理论。
- **rapport**：常被当作"亲近—信任—坦诚披露"的同义词，实际含义滑动且未必随时间增长；过熟有时让敏感问题更难问。
- **沉默（silence）**：不是言语的反面，而是有生产力的材料。分**顺从型**（说了也没用）、**防御型**（怕）、**亲社会型**（为他人保留）。
- **田野笔记（fieldnote）**：把转瞬即逝的现场"铭写"成可查阅文本，必然经过缩减、选择与框定，因此它呈现的是"研究者版本的成员意义"。

### 2.4 分析层

- **编码（code）**：对片段作"概括的、显著的、捕捉本质的"属性指派，是资料与观念之间的过渡动作，不是分析本身。
- **类别（category）**：把同类码聚成的"家族"，需写明纳入规则；边界可以模糊（fuzzy），但不能含糊（vague）。
- **主题（theme）**：**由核心组织概念统合的共享意义模式**。判据是"能否用一个统合性概念把表面不相干的片段串起来"。
- **话题 / 领域（topic, domain）**：资料里"被谈到的东西"，常由提纲引入。只有共享话题、没有共享意义，就还不是主题。
- **核心组织概念（central organising concept）**：主题的脊柱。没有它，标题往往退化为"某类人的某类看法"。
- **分析备忘录（analytic memo）**：写给自己的信、研究者的工作台。记录"为什么这样编码""这属于什么的一个案例""下一步看什么"。
- **编码本（codebook）**：码名 + 定义 + 纳入/排除标准 + 正例 + 反例 + "接近但不对"的边界例。
- **矩阵（matrix）**：两个清单的交集（个案 × 主题、时间 × 行动等）。**设计行列本身就是分析**；矩阵不会自己说话，必须配分析文字。
- **饱和（saturation）**：抽样停止的判据，不是分析产出。且必须说清"对什么单位、按什么判据、阈值多少"。
- **溯因（abduction）**：从"令人惊讶的结果"倒推"若什么为真，它便理所当然"；与归纳（从个案到规则）、演绎（从规则到个案）并列。

### 2.5 质量层

- **可信性 / 可依赖性 / 可确证性 / 可迁移性**：分别类比内部效度、信度、客观性、外部效度，但**只是类比，不是等价物**。
- **三角验证 vs 结晶**：前者假定多来源汇聚即更接近单一真相；后者不求单一真相，求"更复杂、更深、但仍局部"的理解。
- **成员反思（member reflection）**：把发现带回参与者，目的不是"验真"，而是产生新资料与合作性阐释。声称单一真相时才叫"成员核查"。
- **审计轨迹（audit trail）**：把每个研究决策与动作记到"外人可追"的程度。
- **反身性（reflexivity）**：对"我为何做这个研究、我的位置如何塑造所见"的持续记录。不是自我抒情，须照亮读者对现象的理解。
- **可推测披露（deductive disclosure）**：读者能凭邮编、职业、族裔等推断出个体身份，从而造成伤害。匿名不只是改名。
- **伦理四层**：程序伦理（知情同意、保密）、情境伦理（手段能否证成目的）、关系伦理（不把人当素材）、退出伦理（如何离场与发表）。

## 三、方法谱系一览（12 种，判断"该用哪个"时查此表）

| 取向 | 一句话定位 | 最适配的问题 | 常见误用 |
|---|---|---|---|
| 主题分析 | 识别并解释数据集内的意义模式 | "人们如何理解 X""共享意义有哪些" | 把话题清单当主题；套用扎根理论的饱和与信度 |
| 反身性主题分析 | 上述方法中承认研究者立场性的那一支 | 同上，且愿意交代自身位置 | 用编码者间信度"验证"它（范畴错误） |
| 扎根理论 | 从资料生成范畴并整合为理论 | 社会**过程**、机制、行动策略 | 只做编码就自称扎根理论；不做理论抽样 |
| 现象学（描述/解释两支） | 描述经验本质结构 | "这种经验是什么、如何被经历" | 做成"切主题 + 引原话" |
| 民族志 | 长期沉浸，描述文化并解释其运作 | 文化、亚文化、组织日常 | 变成"线上帖子内容分析" |
| 网络民族志 | 以互联网数据为主的民族志 | 线上社群、平台实践 | 把"搜了一批帖子"叫网络民族志 |
| 案例研究 | 在现实情境中深研一个有边界的当代现象 | "如何/为何"，行为不可操控 | 当"小样本统计"；把教学案例当研究案例 |
| 叙事研究 | 分析讲述者如何把生活组织成故事 | 身份、转折、时间经验 | 把引语堆成"故事"；用主题清单替代情节 |
| 话语分析 | 看语言在做什么、产生什么效果 | 建构、立场、权力、意识形态 | 只做内容归类，不接回脉络与效果 |
| 质性内容分析 | 有规则程序、可带一致性检验的范畴化 | 现象由哪些构成特征 | 拿它回答"为什么"与过程问题 |
| 定性比较分析 | 条件组合对结果的充分性 | 跨案例的组态解释 | 把它当"小样本回归" |
| 过程追踪 | 单案例内的因果机制检验 | 机制是否真的在运转 | 只讲故事，不做竞争解释排除 |

**跨取向的共同底线**（可用于回答"这些方法是不是各说各话"）：都从开放阅读言语表达开始；都在整体与部分之间往返；都要求研究者投入但保留距离；都把参与者当作"在其自身权利上的他者"；产出是**从资料中生长出来的**，不是投射或强加。

## 四、知识地图：六层结构

回答"质性研究包含哪些内容""我该按什么顺序学"时，用这张分层图：

```
第 6 层  表达层    写作体裁 / 引文使用 / 审稿应对 / 面向不同读者的转译
第 5 层  质量层    八项标准 / 四检验 / 审计轨迹 / 反身性 / 伦理
第 4 层  分析层    编码 → 类别 → 主题 → 理论；矩阵与展示；溯因
第 3 层  收集层    访谈 / 观察 / 文档 / 影像 / 线上数据；抽样与样本量
第 2 层  设计层    问题类型 → 取向选择 → 案例与比较单位 → 可行性
第 1 层  范式层    本体论 / 认识论 / 四范式 / 理论负荷
```

**层间纪律**：上层选择必须能被下层解释。写作里说"我用了主题分析"，就要能回答"哪一派、为什么、怎么处理编码与主题的关系"。

## 五、学习路径（可直接交付给用户的三套计划）

### 5.1 七天入门（每天 60–90 分钟）

| 天 | 主题 | 产出 |
|---|---|---|
| 1 | 定义与六维边界 | 写下"我的研究问题属于哪一类" |
| 2 | 四范式与理论负荷 | 一句话写清自己的本体论/认识论立场 |
| 3 | 设计谱系，选定取向 | 在谱系表上圈出 2 个候选，写下选/不选的理由 |
| 4 | 抽样与样本量 | 一张抽样矩阵（格子 + 每格人数 + 停止判据） |
| 5 | 访谈提纲与前 15 分钟 | 一份 10 问提纲 + 5 条追问句式 |
| 6 | 编码与主题 | 用 2 页资料做一次开放编码，写 3 条备忘录 |
| 7 | 质量标准 | 用八项标准给自己的一页设计打分 |

### 5.2 二十一天进阶（每三天一个模块）

模块顺序：范式 → 设计 → 收集 → 分析 → 质量 → 写作 → 复核。每个模块的固定动作：读（对应 reference）→ 做（模板）→ 自查（checklist）→ 互评（用 07 的评分表给同伴打一次分）。

### 5.3 九十分钟课堂教学版（讲给本科生/研究生）

1. 开场（10 分钟）：一个"数字答不了的问题"，让听众自己发现质性研究的必要性。
2. 定义与边界（15 分钟）：六维表；三个误解现场纠正。
3. 谱系（20 分钟）：只讲四种（主题分析 / 访谈 / 民族志 / 案例研究），每种给一个"什么问题该用它"。
4. 现场演练（25 分钟）：给一段 200 字访谈片段，让听众两两做开放编码，再对比"为什么你们编出的码不同"——由此引出反身性。
5. 质量（15 分钟）：八项标准里挑三项讲，配"不达标长什么样"。
6. 收尾（5 分钟）：三个自测问题。

## 六、二十道自测题（附答案要点，用于检验学习效果）

1. 质性研究的严谨性来自哪里？→ 系统方法论 + 反身性 + 可信赖性四标准，不是统计检验。
2. "可迁移性"等于"外部效度"吗？→ 只是类比。前者由读者在自身处境中完成，后者靠抽样代表性。
3. 什么时候不该用质性研究？→ 需要估计总体比例/分布、需要检验变量间净效应时。
4. Big Q 与 small Q 的分野是什么？→ 技术与价值是否都为质性；混用即 confused q。
5. "方法论一致性"最先检查哪一环？→ 本体论/认识论与收集、验证手段是否对齐。
6. 目的性抽样与理论抽样的区别？→ 前者在收集前按信息量选点，后者随分析进展决定下一个样本。
7. 为什么说"结构化访谈"在质性里几乎不存在？→ 跨人可比的固定选项实质是问卷。
8. 每个比较格子几个人？→ 经验值是 7–9 人；3–4 人易被特例带偏，超过 9–10 人难以驾驭。
9. 主题与话题的判别？→ 有无统合性核心概念；"某类人的某类看法"通常是话题。
10. 主题为什么不能"浮现"？→ 它否认研究者的主动建构；主题是分析的产出而非投入。
11. 编码与主题的关系？→ 编码是单面向单元，主题是多面的意义模式；编码跨数据项才可能长成主题。
12. 备忘录为什么算"资料"？→ 它承载分析决策，可被再编码、再检索，是审计轨迹的一部分。
13. 饱和必须交代哪四件事？→ 单位、判据、阈值、由谁在何时判定。
14. 反身性主题分析需要多少样本？→ 文献上无最小样本量；应务实设定区间上下限并说明理由。
15. 三角验证的局限？→ 它预设单一现实；在解释/批判/后现代取向中不必然贴合。
16. 成员核查与成员反思的区别？→ 前者暗示单一真相可验，后者产出新资料与合作阐释。
17. 案例研究的外部效度靠什么？→ 分析性概括（理论层面），不是统计概括。
18. 多案例的数量逻辑？→ 复制逻辑；常见规模 6–10 个。
19. 厚描述与厚建构的差别？→ 前者把意义铺开在表面，后者在描述之上再造分析对象。
20. 一份质性论文最容易被拒的三个理由？→ 主题=话题、方法与主张不匹配、证据撑不起结论。

## 七、回答"科普类"问题的固定结构

用户问"什么是 X""X 和 Y 有什么区别"时，用**四段式**，不要一上来堆术语：

1. **一句话定位**（不超过 40 字，用日常语言）。
2. **一个对照**（与最容易被混淆的概念比，给出判别性差异）。
3. **一个例子**（用用户熟悉的场景，标明是"示例"而非研究结论）。
4. **一条边界**（什么时候不适用，或常见误解）。

避免的写法：从哲学史讲起；罗列十几个术语；用"范式""本体论"开场而不解释；把"质性"讲成"定量的初级阶段"。
