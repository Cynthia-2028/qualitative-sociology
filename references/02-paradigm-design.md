# 02 范式、取向与设计选择

> 用于回答"我该用哪种方法""这个研究问题配这个设计吗""为什么说方法要和范式一致"。
> 核心纪律：**先定问题的性质，再定方法**；顺序颠倒就会出现"方法在找一个能用它的题目"。

---

## 一、四范式对照（选方法前的第一道门槛）

| 范式 | 现实是什么 | 研究者与对象的关系 | 什么算好研究 | 常见方法搭配 |
|---|---|---|---|---|
| 实证 | 可被如实观察的单一现实 | 分离，可无偏观察 | 可复制、可检验、可推广 | 量化为主；质性仅作前期探索 |
| 后实证 | 现实独立存在但只能不完美地观察 | 尽量接近，承认误差 | 多重证据、可反驳、可重复 | 混合方法、结构化编码、一致性检验 |
| 建构 | 多重现实，在互动中被建构 | 研究者是现实的一部分 | 可信、可迁移、多声性、反身性 | 反身性主题分析、建构主义扎根理论、叙事、民族志 |
| 批判 | 现实由不平等结构塑造 | 研究者须追问自身权力位置 | 是否揭示权力运作、是否推动改变 | 批判话语分析、行动研究、批判民族志 |

**判据**：把你的研究问题放进上表，看"什么算好研究"这一列是否与你的验证手段冲突。宣称建构主义却用"编码者间信度"验真、宣称批判取向却不谈自身位置，都是范式不一致。

## 二、五套"理论—观察"配置（决定你怎么处理理论与资料的关系）

同一份田野材料，理论的位置不同，写出来的东西完全不同：

| 配置 | 理论的角色 | 典型主张 | 风险 |
|---|---|---|---|
| 厚描述 | 刻意退场，让意义在叙述中层层展开 | "把文化摆在表面上" | 理论被叙述溶解，看不见权力与结构 |
| 扎根理论（经典版） | 悬置，等范畴自行出现 | "让资料说话" | 归纳不产生理论，最后只剩分类 |
| 扩展个案法 | 带着一个"最爱的理论"下场，回到它去证伪或扩展 | "用个案改造理论" | 只看见理论允许你看见的东西 |
| 溯因分析 | 多理论并用而不偏袒，用来回应经验"惊喜" | "惊讶 → 假设 → 检验" | 需要极厚的理论储备，新手难执行 |
| 厚建构 | 用自觉的理论去生产观察，再筛选组装成有纹理的模型 | "造出新对象" | 容易滑向概念堆叠 |

**给用户的判据**：如果你连"我打算让理论扮演什么角色"都答不出，先别急着收集资料——这个问题会在写作阶段以"讨论部分写不动"的形式回来。

## 三、问题类型 → 方法匹配矩阵

把用户的研究问题归类，再对照下表。多选时，取"最不能替换"的那一个。

| 研究问题的问法 | 首选 | 次选 | 说明 |
|---|---|---|---|
| 人们如何经验、定义某个现象？ | 现象学、主题分析、扎根理论 | 叙事研究 | 关注"第一人称的意义" |
| 某现象由哪些核心构成特征？ | 质性内容分析 | 主题分析 | 关注"是什么"，可带分类框架 |
| 这些特征如何与更抽象的概念相关？ | 主题分析（分析式）、扎根理论 | 定性比较分析 | 从描述走向概念 |
| 某一社会过程如何展开？ | 建构主义扎根理论 | 过程追踪、扩展个案 | 关注阶段、转折、策略 |
| 为什么某结果发生（单案例内）？ | 过程追踪 | 解释性案例研究 | 必须排除竞争解释 |
| 什么条件组合导致某结果？ | 定性比较分析 | 多案例研究 | 组态而非净效应 |
| 这个群体的文化是什么？ | 民族志 | 网络民族志 | 长期沉浸不可省 |
| 线上社群如何实践？ | 网络民族志 | 数字民族志 | 参与 + 人的解释，非抓取 |
| 讲述者如何把生活组织成故事？ | 叙事研究 | 生活史 | 关注情节、声音、时间 |
| 语言在做什么、产生什么效果？ | 话语分析 | 批判话语分析 | 分析单位是话语实践，不是人 |
| 在现实情境中"如何/为何"，行为不可操控？ | 案例研究 | 民族志 | 有边界、有情境、多源证据 |
| 要一份可行动的主题清单？ | 编码本式主题分析 | 框架分析 | 应用研究的常见选择 |

**否定式判断**（同样重要）：要估计总体分布、要检验变量净效应、要做预测——质性不是首选。此时应说明"质性可提供机制与意义，但分布问题需另配设计"。

## 四、十二种设计的操作要点与品质判据

### 4.1 主题分析

- **定义**：识别、分析并报告数据集内意义模式的方法族，至少分三派（详见 06）。
- **步骤**：熟悉 → 生成初始编码 → 生成初始主题 → 检视主题（两层）→ 界定与命名 → 写作。
- **品质判据**：主题是否有统合性概念；编码是否跨数据项；摘录是否支撑主张；方法与主张是否同一范式。
- **常见误用**：把提纲问题做成主题；宣称一派却用另一派的质量判据。

### 4.2 扎根理论

- **定义**：以理论生成为目标的系统路径，含三个版本——偏实证的经典版、偏后实证的程序版、建构主义版。
- **骨架**：收集—编码—比较（循环）＋理论感知—理论抽样—理论饱和—理论整合。
- **步骤**：初始编码（动名词、活语码）→ 写备忘录 → 尝试性类别 → 理论抽样补属性 → 理论编码整合。
- **判据**：概念是否"挣得其位"；类别是否有属性与条件；是否真做了理论抽样；能否解释样本内全部变异。
- **常见误用**：只做两轮编码就自称扎根理论；把"理论"降格为"几个主题"。

### 4.3 现象学（描述 / 解释两支）

- **定义**：揭示经验本质结构。描述支用"括置"求去预设的本质；解释支认为研究者的先在理解是理解意义的必要条件。
- **步骤（描述支）**：整体通读 → 切分意义单元 → 逐单元作心理反思 → 澄清结构 → 跨个案本质分析。
- **关键技术**：自由想象变更——问"去掉这一项，它还是该现象吗"，以此确定不变项。**本质分析不靠样本量**，这是它与归纳的分水岭。
- **判据**：是否澄清本质与部分—整体关系；描述是否"读来为真"；是否交代普遍性的层级与限制。
- **常见误用**：做成"切主题 + 引原话"；用来估计频次或检验因果。

### 4.4 民族志

- **定义**：长期沉浸，描述文化（共享规范、知识、行为）并解释其运作。
- **九步**：选社群/文化 → 定关键变量与互动模式 → 文献 → 取得进入 → 沉浸观察 → 找关键报道人 → 多源收集 → 描述模式 → 发展理论。
- **判据**：沉浸是否够深（数月到数年，或多点各一至两周）；是否同时是**嵌入的、结构的、历史化的**（否则退化为"标准故事"）。
- **五条"有机谬误"要主动自查**：只看见面对面互动（忘结构）、期待对象自己开口（忘理论）、美化被研究者（把实践范畴当分析范畴）、忘记实践是两种历史的相遇（忘历史）、把解释绝对化（脱离结构锚定）。

### 4.5 网络民族志

- **定义**：以互联网上自由共享的数据为主的一组收集、分析、伦理与表征实践，要求参与观察与对人的解释。
- **数据**：三种形式——档案式（既有帖子）、引发式（研究者激发的互动）、生产式（共同创造）；四种创造方式——访谈、调查、激发、洞察。
- **十二阶段**：内省 → 探究 → 信息 → 初步访谈 → 检视 → 互动 → 沉浸 → 索引 → 解释 → 迭代 → 实例化 → 整合。
- **选点七标准（各 1–10 分）**：相关性、活跃度、互动性、实质性、异质性、数据丰富度、体验性。
- **判据**：是否长期沉浸、是否有人的参与；"数据越多越民族志"是错的——它是小数据的鉴赏与策展。

### 4.6 案例研究

- **适配三条件**：问"如何/为何"、行为不可操控、研究对象是当代现实情境中的现象（现象与情境边界不清）。
- **定义分两半**：范围（在现实情境中深研有边界的当代现象）＋特征（变量多于数据点、依赖理论命题、靠多源三角）。
- **四型设计**：单案例（整体/嵌入）× 多案例（整体/嵌入）。
- **单案例五理由**：关键个案、极端/异常个案、常见个案、启示个案、纵向个案。
- **多案例**：复制逻辑；逐字复制 + 理论复制；常见规模 6–10 个；2–3 个逐字 + 4–6 个理论复制是常见组合。
- **六种证据来源**：文件、档案记录、访谈、直接观察、参与观察、实物。
- **四检验**：构念效度（多源证据、证据链、关键信息人审阅）、内部效度（模式匹配、解释建构、竞争解释；只适用解释性研究）、外部效度（分析性概括）、信度（案例研究协议、案例数据库，标准是"审计者可重演"）。
- **常见误用**：当"小样本统计"；把教学案例、媒体案例当研究案例；只用一个案例却不给"为什么是它"的理由。

### 4.7 叙事研究

- **定义**：关注讲述者如何把生活组织成有开头—中段—结尾的故事，以及多重声音的对话。
- **三要素**：时间性（序列）、意义（评价）、社会性（为特定受众而讲）。
- **分析路径**：内容取向（说了什么）/ 结构取向（怎么组织，如摘要—定向—复杂化行动—评价—结局—结尾语）/ 表演取向（对谁、产生什么效果）；另有整体—类别、内容—形式两个维度。
- **判据**：是否形成能容纳矛盾的"好格式塔"；是否交代研究者与讲述者的共同建构；是否产出"文本表面所无"的新理解；不得声称终局。
- **伦理特殊性**：叙事研究几乎无法真正匿名（细节本身可识别），须提前与参与者协商呈现方式。

### 4.8 话语分析

- **定义**：语言即社会实践。分析单位是话语实践，不是"人"。
- **步骤**：相对无动机地通读（可隔一周再读）→ 形成关注点 → 在全部材料中选相关片段（宁滥勿缺）→ 对片段迭代分析（替换词项、重框、注意多重功能、注意同异）→ 以文本特征为 claims 作保。
- **常用三问**：X 如何被建构？这段话在做什么、如何做？有什么功能与后果？
- **判据**：每条主张须由文本的具体语言特征支撑；须接回脉络、制度与权力；只做内容归类不足以称话语分析。

### 4.9 质性内容分析

- **定义**：有规则程序、可带一致性检验的范畴化路径。
- **步骤**：定研究问题 → 目的抽样 → 定分析单元（小到有意义、大到可独立成文）→ 熟悉资料 → 发展编码框架 → 试编码与一致性检验 → 正式分析。
- **判据**：编码框架是否穷尽（每个单元都能获得标签）；编码定义是否清楚；是否区分"分析单元"与"收集单元"。
- **边界**：不擅长回答"为什么"与过程问题。

### 4.10 定性比较分析

- **定义**：以案例为条件组合，用布尔代数找充分性组态。
- **步骤**：设计（问题、案例与条件）→ 操作化与二分 → 真值表与矛盾组态处理 → 保守/简约/中间解 → 回到案例解释。
- **判据**：解能否回到案例可读；是否处理矛盾组态与逻辑余项；是否说明反事实假设。

### 4.11 过程追踪

- **定义**：在单案例内检验因果机制是否真的在运转。
- **步骤**：理论化机制 → 推出可观察含义 → 收集证据（如"冒烟枪"式关键证据、必要性检验）→ 排除竞争解释。
- **判据**：证据是否具独特性；竞争解释是否被认真对待。

### 4.12 行动研究

- **定义**：研究与行动结合，与社区一起做研究，而非对社区做研究。
- **循环**：计划（问题识别、策略形成）→ 行动（在做中学）→ 观察（多源资料、三角验证）→ 反思（个体与集体，反馈进下一轮）。
- **判据**：参与者是否真正参与决策；改变是否可追溯；伦理上是否避免"研究完就走"。

```
1. 现象与困惑：____（一句话，不用术语）
2. 研究问题：____（带问号，2–4 个；主题句不带问号）
```

## 六、方法一致性八问（自查 / 评审通用）

1. 我宣称的现实观，和我用来验证的手段，是同一套吗？
2. 研究问题问的是"意义/过程/机制"还是"分布/效应"？方法答得上吗？
3. 抽样的逻辑（目的性 / 理论 / 复制 / 概率）与结论的外推方式匹配吗？
4. 资料类型能回答这个问题吗（访谈能谈机制，但不能替你观察机制）？
5. 分析程序是否写到了"第三步做什么"的程度？
6. 质量判据是否属于我这一派（而不是从别派借来的）？
7. 理论在研究中扮演什么角色，我在方法节里说清了吗？
8. 我的写作体裁（描述式/分析式/批判式）与取向一致吗？

八问里有两问答不上，就先改设计，不要先收集资料。

## 七、常见的设计层错误（评审时高频出现）

| 错误 | 表现 | 改法 |
|---|---|---|
| 方法先行 | 先决定"我要做扎根理论"，再找题目 | 从问题类型出发重选（第三节矩阵） |
| 取向混搭而不自知 | 反身性主题分析 + 编码本 + 信度系数 | 选定一派，全文一致；混搭须说明各取何物、为何连贯 |
| 把"研究问题会演化"当借口 | 收集完了还没定问题 | 明确焦点形成节点（如完成 1/2 至 2/3 资料时应清楚焦点） |
| 抽样与结论外推错配 | 目的性抽样 + 声称"代表中国青年" | 改为分析性概括或可迁移性表述 |
| 案例选择无理由 | "因为方便" | 给出关键/极端/启示/纵向之一的具体理由 |
| 伦理只在附录 | 只在方法节末句"已获知情同意" | 把情境伦理与退出伦理写进正文 |
| 把访谈当万能的 | 用访谈回答"机制如何运转" | 补观察或文档证据，或把问题改为"人们如何叙述该机制" |
