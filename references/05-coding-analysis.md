# 05 编码与分析：从贴标签到讲出机制

> 用于回答"编码怎么编""编码本怎么写""备忘录有什么用""怎么从码到主题到理论""矩阵怎么用"。
> 一条总纪律：**编码是分析的骨头，不是分析本身**。只给码表而不给解释，等于把资料重排了一遍。

---

## 一、编码的五个基本判断

1. **码是最小的意义标签**：一个词或短句，对片段作"概括的、显著的、捕捉本质的、有时是唤起式的"属性指派。
2. **编码是过渡动作**：连接"资料 → 观念 → 回到与该观念相关的全部资料"。
3. **编码是循环的**：第一轮很少做对；至少两轮，常要三到四轮才逐步聚焦。
4. **编码是启发式**："没有公式或算法"；它服务于思考，不替代思考。
5. **编码不是主题**：主题是编码、分类与反思的**产物**，不是被编码的对象。因此不存在"主题编码法"，只有"主题化资料的方法"。

## 二、第一轮编码：七类二十九种（选一种，不要全会）

| 方法 | 适用 | 做法一句话 | 例子 |
|---|---|---|---|
| 属性编码 | 多参与者、多地点，人口学信息关键 | 在资料集开头记环境、参与者特征、时间 | 文件名 `M-SERVER-22-MAY.docx` |
| 量级编码 | 含频次/强度描述 | 在既有码上加符号标强度、方向、有无 | 满意度 5=高、3=中、1=低 |
| 子编码 | 资料形式多样、需细化 | 主码 + 二级标签（父码—子码） | FIGHTING → SCRATCHING / PUSHING |
| 同时编码 | 一段资料有多重意义 | 同一单元同时贴两个以上不同的码 | 排队片段同时标"排队"与"管理秩序" |
| 结构编码 | 半结构访谈、要找主题清单 | 用研究问题衍生的短语给整段贴标签 | 按访谈问题归入一码 |
| 描述编码 | 新手、非访谈资料（笔记、文件、影像） | 用名词概括该段**话题** | "immigration issues""graffiti" |
| 活语编码（In Vivo） | 重视参与者声音 | 直接取参与者自己的词作码 | "no place""damaged goods" |
| 过程编码 | 找例行、节奏、阶段、变化 | **只用动名词** | "lining up for lunch""surviving" |
| 初始编码 | 扎根理论、开放探索 | 拆成离散部分，逐段比较异同 | 一段访谈拆出七个码 |
| 概念编码 | 理论建构、批判研究 | 指派中观/宏观概念 | time、stigma、consuming |
| 情绪编码 | 内心与人际经验、身份、风险 | 标参与者回忆或体验到的情绪 | 区分"回忆的情绪"与"当下的情绪" |
| 价值编码 | 文化价值、信念系统、口述史 | 标价值/态度/信念或其交织 | 对移民言论标"xenophobia" |
| 对立编码（X vs Y） | 冲突性资料、制度民族志 | 用二元形式标直接冲突 | "ADMINISTRATOR VS TEACHER" |
| 评价编码 | 政策、项目、行动研究 | 对价值、功过、意义下判断 | "有效/无效、值得/不值得" |
| 戏剧编码 | 有冲突的田野笔记、叙事呈现 | 用 OBJ/CON/TAC/ATT/EMO/SUB 六要素 | 保住面子（OBJ）—被打断（CON）—沉默（TAC） |
| 母题编码 | 叙事、身份、口述史 | 用反复出现的元素/类型索引 | "superhuman tasks" |
| 叙事编码 | 以故事为认识方式 | 用情节、人物、转折、结局分析 | 按故事结构分析经历 |
| 隐喻编码 | 访谈、叙事、视觉资料 | 标比喻、类比、象征 | "workplace is a war zone" |
| 言语交换编码 | 传播研究、对话实践 | 逐字转写后按交换形式判定类型 | 寒暄作为一类 |
| 整体编码 | 资料量大、先抓整体 | 把一段/一页/一份资料作为整体给"大笔触" | 整段只标 "a lot to learn" |
| 暂定编码 | 有文献或预调研可列先验码表 | 田野前列 start list，收集后增删改 | 从概念框架先列一组码 |
| 假设编码 | 检验假设、分析性归纳 | 用预设码表检验假设，可配频次 | 比较两组在某组码上的差异 |
| 折衷编码 | 新手、资料形式多样 | 有目的地组合两种以上方法 | 活语＋情绪＋价值合用 |
| 协议编码 | 学科已有经检验的编码系统 | 按标准化系统编码 | 套用成熟编码手册 |
| 领域与分类编码 | 民族志、建主题索引 | 找 cover term 与成分术语，建层级 | "street rat""make bank" |
| 因果编码 | 动机、过程、转变 | 追 cause → outcome → link 三元组 | shy → speak up → leadership |
| 主题化（分类式） | 访谈、参与者文件 | 用扩展短语/句子概括话题与模式 | "COPD management requires various treatments" |
| 主题化（现象学式） | 现象学、信念与意义 | 用两个提示句："X is…"（显义）/"X means…"（隐义） | "belonging means feeling grounded" |

**选择原则**：看研究问题、方法论、资料类型与时间精力。新手从描述编码或整体编码起步；要声音用活语码，要过程用动名词，要抽象用概念码，多法并用即折衷。

## 三、第二轮编码：六种（把资料重组）

| 方法 | 作用 | 一句话 |
|---|---|---|
| 聚焦编码 | 扎根理论的主轴动作 | 从初始码中挑最频繁或最有分析意义者，发展最显著的类别 |
| 轴向编码 | 给类别补属性与维度 | 以一个类别为"轴"，标情境、条件、互动、后果 |
| 理论编码 | 收束 | 用"伞状"理论码把范畴整合到核心类别周围 |
| 模式编码 | 跨案例找关系 | 把第一轮码聚成更少、解释力更强的"元码" |
| 精细化编码 | 二次研究、meta 综合 | 带前研究的构念做"自上而下"编码，以细化/修正理论 |
| 纵向编码 | 追踪变化 | 把"变化过程"指派到跨时间可比的资料上 |

**从第一轮到第二轮的四个技法**：

- **编码地图**：把码列成清单，逐轮归类、再归类、概念化（例：52 个码 → 8 类 → 3 类 → 3 个概念）。
- **编码景观**：字号表频次、缩进表层级，做成"文字云＋大纲"。注意：字号只反映频次，**频次不总是重要性的可靠指标**。
- **操作模型图**：用节点、连线、箭头画过程与因果。
- **桌面分类**：把码写在卡片上反复排列；或用"编码的编码"、编码图表。

## 四、编码本：六件套

一个能用的编码本，每条至少包含：

1. **码名**（简短但能独立成立）；
2. **定义**（1–3 句，写清"包含什么"）；
3. **纳入标准**；
4. **排除标准**；
5. **正例**（典型片段）；
6. **反例 / "接近但不对"的边界例**。

**判断码好坏的三个测试**：

- 脱离上下文还成立吗？（"福祉指引不可关联"——缺脉络，坏码）
- 指向明确吗？（"正向性"——指向不明，坏码）
- 它是否跨一个以上数据项？（只出现一次可以是重要发现，但不能撑起一个主题）

**码的增殖控制**：只编与研究问题相关的"相关文本"；做"合并者"而不是"切分者"；刻意重复使用码；边编边归并。判断标准很直接：**如果你从不重复使用一个码，你可能只是在缩写资料，不是在编码。**

## 五、分析备忘录：研究者的工作台

**性质**：不是资料摘要，而是"写给自己的信""实验室笔记本"。**它本身也是资料**，可以被再编码、再检索。

**格式**：日期 + 标题（标明类型：码的定义 / 断言 / 理论 / 伦理困境）+ 副标题；单独成文件，不嵌在田野笔记里。

**内容（十问）**：

1. 我为什么用这个码？它的操作定义是什么？
2. 这段资料让我想到什么模式、类别、主题？
3. 它与哪些码相连？属于什么更大的过程？
4. 与文献、理论有什么关系？
5. 有什么反例？我怎样处理？
6. 这属于"什么的一个案例"？
7. 我自己的反应是什么？有没有伦理困境？
8. 下一步该问什么、看什么、找谁？
9. 这个判断如果错了，会错在哪里？
10. 如果要把这段写进论文，我会怎么开头？

**写作纪律**：像给亲密朋友写信，不必写成僵硬学术体；先自由写，再判断它属于哪类 memo 并命名；**不要等到分析结束后补写**（事后洗白与"追溯式顿悟"是审计轨迹的污染）。

**链路**：田野速记里的"分析便利贴" → 扩展为 memo → memo 的段落再织入最终报告。

## 六、矩阵与展示：设计行列就是分析

**核心命题**：你展示什么，就决定你能知道什么。行、列、单元格内容的设计本身就是分析活动。

**三类基本结构**：矩阵（行列）、网络（节点＋连线）、清单（排序）。

**按用途分的常用类型**：

| 用途 | 典型展示 |
|---|---|
| 探索 | 资料账目日志、接触摘要表、个案摘要、解释性效果矩阵、清单矩阵、对比表 |
| 描述 | 角色排序矩阵、情境图、构念表、概念聚类矩阵、认知地图 |
| 排序 | 事件列表矩阵、成长梯度、时间排序矩阵、决策模型、事件—状态网络 |
| 解释 | 变量×变量矩阵、效果矩阵、案例动力矩阵、因果链、案例内因果网络、跨案例因果网络 |
| 预测 | 预测—结果—后果矩阵、因果预测模型 |

**矩阵分析十步**：

1. 看研究问题与关键变量，铅笔在纸上画草图。
2. 请同事看格式，帮你发现预设与替代排法。
3. 定行列表头（个案、角色、场景、行动、事件、策略、意义、情绪、过程）。
4. 用表格软件或质性软件建模板；**尽量一屏或一页读完**。
5. 变量不超过十几个，五六个更可控；多了做元矩阵（行中行、列中列）。
6. 试填数据；格式不好用会立刻暴露；必要时转置行列。
7. **明确记录决策规则**：什么算"提及"、什么算"高/中/低"、缺失与歧义怎么标。
8. 先"眯眼扫描"看行列与路径，再仔细核对（找模式、作对比、聚类、计数）。
9. 回原始笔记做"地面校验"；请同事与参与者看。
10. 写分析性文字——**展示从不自己说话**。

**跨案例的纪律**：先做厚实的案例内分析，再把可比的案例"堆叠"成元矩阵；**不要只把变量相加**，那会摧毁案例内的因果网。

## 七、从码到类别到主题到理论

### 7.1 四步递进

1. **码 → 类别**：把"看起来像、感觉上像"的码聚成家族，给每个类别写一条**纳入规则**并配样例资料。
2. **类别 → 主题**：把名词类别改成动名词以显过程；用"触摸测试"追问它到底在讲什么（例：Drug use → dependency / addiction / coping / escaping）。
3. **主题 → 关系**：比较主题之间的关系——序列、并发、多米诺、网络、条件—行动—后果。
4. **关系 → 理论**：把主要码、类别、主题织进尽可能少的句子里，形成可被反驳的断言（codeweaving）；再写几个版本，主动找反证。

### 7.2 三种"再往前一步"的路径

**(A) 溯因分析：从"惊讶"出发**

- **重访**：同一份材料反复重新经验（笔记、转录、编码、备忘录都是"重访装置"），让现象在不同时刻重新安置相关性。
- **陌生化**：通过书写制造与"理所当然"的语义距离，让被视而不见者成为焦点。
- **替代性框定**：强行用多个理论框架读同一小段资料（"从职业系统理论看？从责任组织理论看？从情境行动看？"），使同一现象可比于不同现象。
- **纪律**：刻意收集**负面个案**；"收集确证个案几乎没有方法论价值"。

**(B) 目标—障碍—策略—后果（GOSI）：把行动放回中心**

- 入口不是主题词，而是"**奇怪/反直觉的一刻**"；先问"这里的人在解决什么问题"。
- 在页边标 G、O、S、I 四要素，各配一个简短"把手"。四要素不必按顺序出现：田野常先看到策略，访谈常先听到目标，要前后推断。
- 补缺：只看到策略就问"他要达成什么、什么在阻挡、这带来什么"；只听到目标就问"他做了什么、遇到什么"。
- 收束问句："**这是什么的一个案例？**"
- 理论抽样：带着四要素结构去选对比地点、人群、时点（换族裔、换街区、换学校，看障碍是否改变、策略是否改写）。

**(C) 扎根理论的三级编码**

开放（打散、比较、概念化、范畴化，标属性与维度）→ 轴向（用"条件—情境—行动/互动策略—后果"重装）→ 选择性（围绕核心范畴形成解释模型）。
**注意**：轴向编码不是必经之路；它可能抑制理论编码，也可能把一个开放过程过早结构化。

### 7.3 类别、主题、理论的判别

| 层次 | 形态 | 判别问题 |
|---|---|---|
| 码 | 词或短句 | 它标的是片段的一个面向吗？ |
| 类别 | 词的家族 + 纳入规则 | 边界清楚到别人也能用吗？ |
| 主题 | 扩展短语/句子，含统合概念 | 能否用一个核心概念把多个码串起来？ |
| 理论 | 可被反驳的命题 | 它是否解释了"为何如此"并指出了条件？ |

## 八、阈值与数量：可引用的区间

| 项目 | 数值 | 性质 |
|---|---|---|
| 单个码的长度 | 不超过五个词；活语码更短 | 建议 |
| 起始码表 | 12–50 个 | 建议（结构清楚时可在短期记忆里掌握） |
| 一次能处理的码数 | 30–40 个 | 建议 |
| 一个研究的最终码数 | 50–300 个，"绝不要上千" | 建议 |
| 教育类研究的典型漏斗 | 80–100 码 → 15–20 类 → 5–7 个概念 | 经验 |
| 精简编码漏斗 | 5–6 个暂定码 → 不超过 25–30 类 → 5 或 6 个主题 | 建议 |
| 核心主题上限 | 最多 6 个较稳（有研究用 10 个） | 建议 |
| 一个码值得注意的共识度 | 约 1/4 参与者共享值得考虑；约 3/4 才算"共性" | 经验（单例也可能关键） |
| 编码一致性 | 80–90%（另一说 85–90%） | 建议；质性研究"没有标准或基线百分比" |
| 团队编码会议人数 | 不超过 5 人 | 经验 |
| 可删除/概括的资料比例 | 最多 1/2 到 2/3 | 经验（风险是删掉关键反例） |
| 正式发表引用的访谈摘录比例 | 不超过 4% | 经验 |
| 矩阵变量数 | 不超过十几个；5–6 个更可控 | 建议 |
| 临时个案摘要长度 | 5–35 页 | 建议 |

## 九、常见错误（评审最常打的点）

1. **把编码当计数**：频次高不等于重要；"计数容易，思考难"。
2. **把编码当分析**：编码只是"一种"分析方式，且不总是合适。
3. **把编码当主题**：把"某话题的若干看法"命名为主题，是最常见的失分点。
4. **没有备忘录**：边缘的码"只是标签，直到被分析"；不写 memo，码表会退化成清单。
5. **码的增殖**：几百个码堆在桌上；对策是只编相关文本、合并、重复使用。
6. **过度同时编码**：一段贴太多码，可能说明"没有清晰的研究目的与镜头"。
7. **类别边界含糊**：可以模糊（fuzzy），不能含糊（vague）；一个码被归入太多类别，说明定义不清。
8. **矩阵过早定型**：展示会变成"紧身衣"，迫使资料进入表面可比、实则琐碎的维度。
9. **让展示自己说话**：结论不在"地面层"回原始笔记校验，就不可信。
10. **信度检验误用**：评分者间信度只适用于"所有人被问同样问题、同样顺序、最后一次性编码"的半结构访谈；统一编码单元就能显著抬高 kappa——**一致性可以被方法"做"出来**。
11. **把饱和当"没新码"**：饱和指属性、维度、条件、行动/互动、后果都不再新增。
12. **只分类不理论化**：产出"主题清单"而不推进解释社会过程的概念框架，是"蝴蝶收藏"——标本整齐，却没有生境与演化。

## 十、分析节写作模板（可直接套用）

```
1. 分析路径：说明用哪种取向、为什么、如何处理"编码—类别—主题"的关系。
2. 编码过程：第一轮用什么方法、第二轮如何重组、码表如何演化（给码数变化）。
3. 备忘录与反身性：写 memo 的时机与作用；自己的位置如何影响编码。
4. 从码到主题：给一个具体例子（一个主题如何从 3–4 个码长出来）。
5. 反例处理：主动说明找了哪些负面个案、如何处理。
6. 停止判据：单位 + 判据 + 阈值（见 03）。
7. 软件与工具：用了什么、做了什么、没做什么（软件不替你分析）。
```
