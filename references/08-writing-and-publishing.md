# 08 写作与发表：从资料到可发表的论文

> 用于回答"质性论文怎么写""方法节要交代什么""结果部分怎么组织""讨论怎么写才不像总结""审稿说我只描述不解释怎么办"。
> 一条底线：**质性论文不是"把访谈摘录排好"，而是"用材料讲一个有论证的关于社会的故事"**。

---

## 一、论文骨架（质性版 IMRAD）

| 节 | 要完成的任务 | 常见篇幅占比 |
|---|---|---|
| 引言 | 让读者在意：一个经验困惑 + 一个知识缺口 + 一个问题句 | 10–15% |
| 文献与框架 | 不是综述全部相关研究，而是搭出"能看见你的发现"的取景框 | 15–20% |
| 方法 | 让人能判断可信性、能复述、能评估伦理 | 15–20% |
| 发现 | 主题陈述 + 证据 + 解释，三层交替 | 40–45% |
| 讨论 | 回答"所以呢"：与理论对话、给出机制、说明边界 | 10–15% |
| 结论 | 一段话讲清贡献，不重复摘要 | 3–5% |

**引言四段式**（可套用）：

1. **现象**：一个具体的、读者能认出的社会现象（不用术语）。
2. **张力**：关于它，我们以为 A，但经验上出现 B。
3. **缺口**：现有研究解释了哪一半，漏了哪一半（点名到机制层，不是"研究不足"）。
4. **本文**：问题句 + 一句方法 + 一句贡献。

---

## 二、方法节必报的十二项

不写全，评审一定会问；写全了，很多质疑会自动消失。

1. **取向与理由**：用了哪种取向、哪一派（若为主题分析必须点明）、为什么不选邻近方法。
2. **范式立场**：一段话说清本体论/认识论，以及与验证手段的关系。
3. **抽样**：逻辑、维度、格子设计、每格人数、纳入/排除标准。
4. **样本量**：单位—判据—阈值—设计特征（见 03）。
5. **收集**：时间跨度、地点、媒介（面对面/视频/电话）、时长、语言、录音与转写规则。
6. **工具**：提纲如何形成与修订（做了几次修订、在第几个访谈后）。
7. **研究者**：访谈者训练、身份与位置、与受访者的关系、可能的权力不对称。
8. **分析**：编码几轮、用什么方法、备忘录做法、如何从码到主题、主题如何检视。
9. **软件**：用了什么、做了什么、**没做什么**（软件不替你分析）。
10. **质量动作**：至少四项（延长投入、负面个案、审计轨迹、同行审议、成员反思、多源证据）。
11. **伦理**：四层（程序/情境/关系/退出）+ 可推测披露的处置。
12. **限制**：不声称什么；哪些维度未能纳入。

**写法提示**：方法节不是"辩护状"，而是"说明书"。少用"严格遵循""确保信度"这类保证式语言，多用动作与判据。

## 三、发现部分：三层交替

### 3.1 结构单位

每个主题用一个"**陈述—证据—解释**"的三段循环：

1. **陈述**（2–4 句）：这个主题讲什么、边界在哪、与其它主题什么关系。
2. **证据**（2–4 条摘录）：长短交错；每条摘录前有引导句，后有分析句。
3. **解释**（2–5 句）：这条材料为什么支持该主题？它揭示了什么机制、张力或条件？

### 3.2 主题命名

- **断言式**优于名词式："稳定被重新定义为一种可携带的资产" > "对稳定的看法"。
- 允许有张力："越努力越不被看见" > "努力的作用"。
- 必要时用一小段摘录作标题，再给一个简短的分析性子标题。

### 3.3 引文使用的四条规则

1. **每条引文都必须"被使用"**：出现后必须有一句分析，说明它做了什么。
2. **不做摘录串烧**：连续三段引文而无分析，是"没有做分析"的典型标志。
3. **"有人表示"不是分析**：用"有受访者表示"开头而无论证，等于把解释权交给材料。
4. **比例控制**：正式发表引用的访谈摘录通常不超过资料总量的极小比例（经验值约 4%），说明"选"本身就是分析。

### 3.4 主题顺序

- 按**论证逻辑**排，不按重要性或出现频率排。
- 常用顺序：奠基性主题 → 张力最强的主题 → 转折主题 → 收束主题。
- 第一个主题要"易读且能立住基调"；最后一个主题要能自然过渡到讨论。

## 四、讨论部分：从"总结"到"论证"

**四段式**：

1. **回答**：用两三句直接回答引言的问题（不要复述发现）。
2. **对话**：与 3–4 个具体研究/理论对话——你的发现是**印证、修正还是反驳**？给出机制层面的解释。
3. **提升**：把发现提到概念层：这是什么的一个案例？它改变了哪个概念的用法？
4. **边界**：不声称什么；可迁移到哪些情境；需要什么后续研究。

**避免的三种写法**：

- "本研究发现了三个主题，分别是……"（这是摘要，不是讨论）
- 把局限写成免责声明（"样本有限，结论仅供参考"）
- 用"具有重要的理论与实践意义"结尾（空心句）

---

## 五、理论化：三个可操作动作

1. **命名机制**：给你的核心过程起一个可辨识的名字（不是标签，而是过程名）。
2. **给条件**：说明该机制在什么条件下成立、在什么条件下反转。
3. **给对手**：提出一个"如果我的解释错了，会看到什么"的可观察含义。

**判断是否理论化**：把"研究对象"换成另一群人，你的结论还成立吗？若成立，说明你讲的是机制；若只对这群人成立，说明你讲的是描述——两者都可以，但要自称清楚。

## 六、期刊定位与投稿准备

| 稿件类型 | 读者期待 | 写作重心 |
|---|---|---|
| 综合社会学期刊 | 理论增量 + 方法透明 | 讨论与理论对话要厚 |
| 专业领域期刊（教育、健康、传播） | 实践含义 + 可行动建议 | 发现要具体，建议要可执行 |
| 方法学期刊 | 程序创新 + 可复制 | 方法节与反思要占更大篇幅 |
| 区域/国别研究期刊 | 情境特殊性 | 语境描述与历史维度要足 |

**投稿前必做四件事**：

1. 目标刊近三年是否发过同取向论文？引 2–3 篇作为"体裁参照"。
2. 字数与结构是否符合该刊惯例（质性论文常需更长篇幅）。
3. 摘要是否写出"问题—方法—核心主题—贡献"四件（不要写"本文探讨了……"）。
4. 匿名化是否彻底（致谢、文件属性、自引方式）。

## 七、审稿意见的三种典型类型与应对

| 类型 | 审稿人原话的样子 | 应对策略 |
|---|---|---|
| 范式错配 | "作者应报告编码者间信度""应说明如何控制偏差" | 不照做也不硬顶：一段方法学说明 + 改用本派判据 + 补"互检"记录 |
| 样本与外推 | "样本太小，结论无法推广" | 改表述（分析性概括）+ 补停止判据 + 明确贡献层级 |
| 深度不足 | "论文停留在描述层面" | 补主题间关系、补反例、讨论段提出机制与条件 |

**回信结构**：编号 → 结论（接受/部分接受/不接受）→ 改动位置 → 若拒绝，给方法学理由（不辩论品味）。

---

## 八、面向不同读者的转译（同一份研究的三种写法）

| 读者 | 开头 | 证据 | 结尾 |
|---|---|---|---|
| 学术同行 | 概念张力 | 摘录 + 理论对话 | 概念修正 |
| 政策/实务部门 | 一个可识别的困境 | 类型学 + 案例 | 可执行建议（3 条以内） |
| 公众/科普 | 一个场景 | 一两个故事 + 一句机制 | 一个可带走的问题 |

**转译纪律**：不改变结论、不夸大范围、不删掉反例；把"我认为"改成"研究发现"时，要确认证据真的支撑。

## 九、写作自查清单（交稿前逐条打勾）

- [ ] 标题是断言或张力，不是"……研究"
- [ ] 摘要四件齐全，且没有"本文认为"式空话
- [ ] 引言第三段点名了"漏掉的那一半"
- [ ] 方法节十二项至少覆盖十项
- [ ] 每个主题都有界定句，且能用两三句话说清
- [ ] 每条摘录后都有分析句
- [ ] 至少处理了一个反例
- [ ] 讨论段回答了"所以呢"，并给了条件与边界
- [ ] 局限不是免责声明，而是"不声称什么"的清单
- [ ] 全文没有"主题浮现"这类被动叙述
- [ ] 术语首次出现有定义，且全文一致
- [ ] 参考文献与正文一一对应
