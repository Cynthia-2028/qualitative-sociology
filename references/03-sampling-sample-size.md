# 03 抽样、样本量与"抽到什么时候停"

> 用于回答"要访谈多少人""饱和是什么""评审问我为什么是 25 个人怎么办""样本太少能不能做"。
> 铁律：**样本量的每一个数字都必须带三样东西——单位、判据、依据类型**。只说"我访谈了 20 人"在方法学上等于什么都没说。

---

## 一、抽样的六种逻辑（先选逻辑，再谈数量）

| 逻辑 | 做什么 | 何时用 | 常见误用 |
|---|---|---|---|
| 目的性抽样 | 按"能否提供信息"选人/点 | 默认逻辑，几乎全部质性研究 | 变成"谁方便找谁" |
| 最大变异抽样 | 刻意拉开关键维度（阶层、地域、年龄） | 要描述差异范围 | 差异维度选错，变成"人多但同质" |
| 极端/关键个案 | 选最能放大机制的个案 | 检验理论、揭示通常被遮蔽的运作 | 只讲"精彩个案"，不给选择理由 |
| 理论抽样 | 边分析边决定下一个样本，补范畴属性 | 扎根理论 | 声明做了，实际按名单走完 |
| 滚雪球 | 靠熟人背书逐层扩展 | 难以接触的群体、精英网络 | 同质性滚成"一个圈子" |
| 分层随机 | 总体可知时，按维度随机抽 | 专家/精英访谈、总体名单公开 | 总体不可知却硬套 |

### 1.1 目的性抽样的四条实操判据

1. **受访者必须是所问主题的专家**。医生能谈"如何提供照护"，不能替病人谈"就医体验"；问孩子的学校生活就问孩子，不要问家长"孩子怎么想"。
2. **不要问"别人怎么想"**。这类问题得到的是受访者的推测，不是他人的经验。
3. **比较设计要"苹果对苹果"**。先把关键维度拉平（同一年龄段、同一城市类型、同一制度位置），再让你要解释的因素自然变化。
4. **群体数量要克制**。除非问题要求，通常控制在一个种族/族裔群体、年龄段（未成年 5 岁以内、成人两个十年以内），并弄清出生地与身份状态。

### 1.2 滚雪球的技术细节

- 依靠**弱 tie**，请熟人背书，而不是冷邮件。
- 先请求"15 分钟电话"，而不是"90 分钟访谈"；并说明"同意通话不等于同意参加研究"。
- 正式请求放在通话里或当面提出。
- 访谈结束、走到门口时再问"你碰巧还认识……吗"，问完**等几秒**，不催促。
- 限制从同一个人处获取的受访者数量，避免一个小圈子被当成一个群体。

### 1.3 分层随机：总体可知时的替代方案

当潜在受访者总体有公开名单、群体内部差异可辨识时，雪球会系统性排除重要立场。此时可分层随机：

1. 构建总体（公开名单、去重、与外部数据交叉）。
2. 定第一层变量（可从公开信息获得的：所属部门、参与频次、角色、结果状态）。
3. 定第二层变量（需对抽中者逐一核查的：性别、方法偏好、时间顺序）。
4. 按"每格至少一人"设槽位，随机填槽。
5. 分批邀请、设跟进轮次，未回者与拒访者进入下一轮。
6. **把无法纳入的变量写进限制**（如学科、国籍、年龄常缺可靠数据源）。

## 二、每个格子多少人：可用的经验值

| 场景 | 数字 | 性质 |
|---|---|---|
| 每个比较格子 | **7–9 人**（个人经验下限） | 经验主张 |
| 每格 3–4 人 | 太少，易被一个特例带偏 | 经验主张 |
| 每格 5–7 人 | 若已看出模式，可比较有信心 | 经验主张 |
| 每格超过 9–10 人 | 研究变得笨重，边际收益下降 | 经验主张 |
| 2 群体 × 3 阶层 | 7–11 人/格 → 42–66 人；"每格 7 人共 42 人，比每格 11 人共 66 人容易得多" | 经验主张 |
| 本科生课程作业 | 4–5 个访谈 + 8–10 次观察笔记 | 教学经验 |
| 学期论文 / 迷你研究 | 少于 10 个访谈不算偷工减料 | 教学经验 |
| 硕士论文量级 | 25–30 个访谈 | 经验主张 |
| 最终码数 | 50–300 个，"绝不要上千" | 方法建议 |
| 核心主题数 | 最多 6 个较稳（有研究用 10 个） | 方法建议 |

**关键提醒**：这些是"经验值 / 建议值"，不是"标准"。写进论文时要写成"参照……的经验区间，本研究每格设定 8 人"，而不是"按标准必须 8 人"。

## 三、十种分析类型的样本量对照（最常被问、也最容易被搬错的一张表）

> 使用说明：同一个"n"在不同类型里指完全不同的东西——访谈次数、焦点小组场次、自由列举份数、数据文件数、案例数。**跨类型搬数字是量级错误。**

| # | 类型 | 要回答什么 | 样本量 | 依据强度 |
|---|---|---|---|---|
| 1 | 主题（数据）饱和 | 这份语料里有哪些主题 | 访谈 **9**（均值 12–13）；焦点小组 **4** 场（均值 5–6）；早期结论为 **6–12** 次可识别约 **90%** 主题 | 实证测定 |
| 2 | 意义饱和 | 一个主题内部的意义变异有多少 | 访谈 **24**；焦点小组 **8** 场 | 实证测定 |
| 3 | 元主题饱和 | 跨点共享的主题是什么 | 每点 **20–40** 次访谈；**20** 次内可见全部元主题；要"可靠"（每点每主题至少出现 **3** 次）需多至 **39** 次 | 单一实证 |
| 4 | 显著性饱和 | 当地人最看重哪些条目 | 自由列举 **10** 份可覆盖 **95%** 显著条目 | 实证测定（须穷尽式引出 + 恰当追问） |
| 5 | 理论饱和 | 范畴属性是否已补满 | **20–30+** 次访谈；**理论样本量无法先验确定** | 建议值 + 回溯 |
| 6 | 反身性主题分析 | 如何以自身立场解释意义 | **无**最小样本量；应务实设定区间上下限 | 无（文献空缺） |
| 7 | 民族志 | 这个群体的文化是什么 | 主题饱和路径 **50–81** 份数据文件（50＝33 次观察笔记＋17 份访谈；81＝55＋26）；文化共识路径 **20–30** 次结构化访谈 | 单一实证 + 共识模型 |
| 8 | 图式分析 | 背后的文化脚本是什么 | **无**明确指南；"借用 20–30"只是主张，未验证 | 无 |
| 9 | 经典内容分析 | 各类目在总体中的分布 | 由**统计功效分析**决定，无固定数；前提是随机样本或全语料普查 | 方法成熟 |
| 10 | 质性内容分析 | 如何系统归类并解释语境 | 由**信息力量**决定，无固定数 | 概念框架 |

### 3.1 五类饱和的分工（不要混用同一个"饱和"）

- **主题饱和**：管"有没有"，回答"主题清单是否列全"。最常被用，也最容易被当成万能判据。
- **意义饱和**：管"有多深"，回答"我能否解释这个主题的内容、细微差别与变异"。**对描述性主题分析最贴合**。
- **元主题饱和**：管"跨点共享"，用于多点/跨文化比较。
- **显著性饱和**：管"文化重要性排序"，用于自由列举。
- **理论饱和**：管"范畴属性是否补满"，只属扎根理论。

**常见误判**：用主题饱和的数字去支撑一个理论性结论——"识别主题所需的最小样本量，不等于你有足够资料去做别的分析"。

### 3.2 反直觉的两条实证发现

1. **元主题饱和在异质样本中反而更省**：异质样本少至 **18** 次即可，同质样本却需 **35–39** 次（此发现尚待复制）。这与"同质样本省样本"的常识相反。
2. **追问浅会制造"假饱和"**：追问少 → 主题少 → 很快"饱和" → 误判小样本已足够。这是最危险的一种自我说服。

### 3.3 会削弱样本效率的设计特征（申报时必须交代）

- 访谈媒介：网络访谈的主题饱和需 **30–67** 次，明显高于面对面。
- 问卷认知访谈：需 **55–75** 人才能发现多数高影响问题。
- 领域边界：有界领域（"说说你撤离时走的路线"）主题少；无界领域（"说说你的迁移经历"）主题多。
- 议题敏感性：敏感健康议题在焦点小组更易开口；政治敏感或公正议题相反。
- 焦点小组规模：4 场不等于 4 人，规模本身影响结果。

## 四、申报样本量的四要素写法（可直接套用）

写不出这四行，评审一定会问。

```
单位：本研究的 n 指____（访谈次数 / 参与者人数 / 焦点小组场次 / 数据文件数 / 案例数）
判据：以____（主题饱和 / 意义饱和 / 信息力量 / 理论饱和 / 反身性务实区间）作为停止依据
阈值：当____（连续 3 次访谈无新主题 / 达到 80% 主题覆盖 / 每格补满至 8 人）时停止
设计特征：因____（网络访谈 / 议题敏感 / 群体异质），在经验区间基础上上调至____
```

**示例句式**（可直接改写）：

> 本研究采用目的性抽样，按"城市类型 × 家庭资源"设 6 格，每格 7–8 人，共访谈 45 人。停止判据为**意义饱和**：当连续 3 次访谈在既有主题内部不再产生新的意义变体时停止。因访谈以视频方式进行，参照网络访谈的经验区间（30–67 次），本研究在格数设计上预留了 20% 的追加空间。

**不要这样写**：「根据饱和原则，本研究访谈了 20 人。」——缺少单位、判据、阈值与判定者。

## 五、"样本太少"该怎么回应

评审说"样本太小"时，有四种合法回应，按优先级排序：

1. **改判据**：说明本研究走的是意义饱和而非理论饱和，或走的是反身性主题分析（本就无最小样本量），并交代务实区间与理由。
2. **改外推方式**：把"代表"改成"分析性概括"，明确结论的层级（机制、过程、类型），不做分布推断。
3. **补证据类型**：加文档、观察、比较案例，用多源证据提高每个个案的信息密度。
4. **承认限制**：在局限里写明"本研究不追求样本代表性，其贡献在于机制识别，其可迁移性由读者判断"。

**不要做的**：事后把"方便抽样"改写成"目的性抽样"；用" saturation" 一词代替论证；把访谈次数说成参与者人数。

## 六、抽样节自查清单

- [ ] 抽样逻辑说清了（目的性/理论/复制/概率），且与结论外推方式一致
- [ ] 每个格子的选择理由写明了（不是"方便"）
- [ ] 受访者确实是所问主题的专家（不是替他人代言）
- [ ] n 的单位前后一致（访谈数 ≠ 人数 ≠ 场次）
- [ ] 停止判据写了单位、判据、阈值
- [ ] 依据类型标注了（实证测定 / 建议值 / 无指南）
- [ ] 设计特征（媒介、敏感性、异质性）对样本量的影响有交代
- [ ] 未纳入的维度写进了限制
